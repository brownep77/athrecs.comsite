# Comrades Marathon fixture and results-link profile

Checked: 2026-08-20

## Published in the Athrecs catalogue

- One canonical `comrades-marathon` road-ultramarathon series.
- Completed editions from 2022 through 2026, using the organiser's official dates and measured
  route distances.
- The confirmed 100th edition on 13 June 2027. Its Down Run direction is known, but the measured
  distance and entry details remain TBC.
- An official Comrades results link for every completed edition.
- The latest organiser-published qualifying table, clearly labelled as 2026 reference data until
  the 2027 centenary rules are published.

## Rights-safe handling

The Comrades site links its historical archive to FinishTime. Both `comrades` and `finishtime_za`
remain disabled in the bulk source registry pending a dedicated rights review. Athrecs stores the
public fixture facts and links to organiser-hosted result pages; it does not reproduce FinishTime's
participant database or infer athlete identities from names.
