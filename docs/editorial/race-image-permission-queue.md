## Permission request checklist
Request rightsholder name; permission for athrecs.com editorial event page; catalogue and social preview thumbnails; organic and paid social use separately; crops/resizes; duration, geography; attribution; whether the organiser can authorize photographer rights; whether image features minors or other restrictive permissions. Store evidence and expiry. If not granted, select a properly licensed alternative.
