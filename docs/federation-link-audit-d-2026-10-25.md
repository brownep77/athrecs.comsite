# Federation link audit D — 25 October 2026

This pass screens all 75 direct road-running or track-and-field-tagged federation URLs, excluding funding/Olympic bodies and membership-only references. It follows 32 linked detail destinations. Earlier aquatics, triathlon and cycling audits remain intact.

## Findings

Fifty-five homepages returned organisation-related content, 12 returned partial content, four need content review and four primarily exposed older material. These are content-screening outcomes, not independent verification of every organisation fact or downstream record. Poland was readable through a web fallback after an initial 502; Guatemala still returned only a JavaScript-required shell. A retrieval failure does not establish that a domain is wrong.

French seasonal calendar/results routes redirect from 2026 to 2027. The direct competition indexes contain named entries, but their existing copying restriction remains in force: discovery only, followed by organiser verification. No French participant or event tables are retained in this audit. The public French directory entry now points to the direct calendar/results indexes and explains the seasonal distinction.

Athletics Ireland's current fixtures/results route contains dated competitions and links to timetables and results, mixed with non-race items. Its legacy results route redirects to an old article with 2014 links, while the older events-calendar route resolves to News & Blog without fixtures. The directory now references the current route, retaining the original governance references.

Athletics Kenya's calendar/results first page contains November 2020 entries. Its homepage also contains placeholder text, and its athlete route yielded navigation only. The directory and source coverage now qualify the index as historical first-page evidence; later pagination was not assessed. This is not a claim that Kenya has no current competitions.

## Deeper sources and limitations

Scottish Athletics' athlete page is a participation/performance information hub rather than a biography directory. Its calendar returned navigation; View Event List redirects to the events-information hub, and the federation-linked JustGo search yielded a loading shell. No named fixture rows were confirmed. A broken Facebook widget does not establish an invalid federation domain.

Australian Athletics' homepage pairs a 2027 event title with a 2026 date. Its calendar and athlete index did not yield named records, although its results index contains 2025/2026 and historical document links. Romania's results index has a 3036 date typo. Both discrepancies need edition-specific reconciliation before data use.

Athletics Canada exposes a labelled rankings table with a separate wind-assisted section, but a homepage/profile birthplace field contains a nationality adjective. That conflicting field is held for clarification; neither birthplace nor nationality is inferred. Individual field-label evidence remains in the private staff audit.

Finland's calendar/results hub and Greece's athlete index were readable through web fallback despite cookie-only primary extraction. Uruguay's 2026 results index is useful despite older homepage news. Trinidad and Tobago's event/results table mixes current and historical editions, while its athlete directory has old update dates. Indonesia's roster is explicitly 2024 and its opened championship reference is 2025. Ecuador and Luxembourg need individual event-page checks for complete dates.

## Registry and validation

Twenty-six disabled/manual research sources were added after full-registry URL and ID duplicate checks. Seventy-eight existing records receive dated observations, preserving their original notes and restrictions. All new sources are mapped to their organisations. The registry grows from 990 to 1,016 rows, with 36 enabled and 980 disabled; the 12 sources added by a concurrent urgent-start review are preserved. Three public directory entries change; the directory still contains 740 organisations.

Source schema, organisation coverage, collection counts, preservation of existing records, directory validation, TypeScript, focused lint and a development build are checked before release. Live page checks follow deployment. Private evidence includes source captures, retrieval limitations and before/after registry records, with restricted French data omitted. No fixture, start-time, athlete, nationality or result records are imported or verified by this link audit. Registration does not establish collection rights or enable automated collection.
