# Road half-marathon guides

Thirty selected road half-marathon guides across the same seven countries as the road marathon guides: UK (6); Ireland, USA, Canada, Australia, New Zealand and South Africa (4 each). This is a curated starting collection, not a complete national calendar.

Source information was checked on 26 September 2026. Each record carries its organiser, course, entry, date and results links. Announced dates cover the remaining 2026 season and 2027. Unconfirmed editions, including permit-pending Limerick, stay TBC and create no SportsEvent structured data. Past results belong only to the half-marathon distance.

The two distances share layout, date expiry and SEO helpers. Half-marathon records explicitly carry 21.0975 km; existing marathon records retain 42.195 km behaviour. Country links, breadcrumbs, FAQs, canonicals and sitemap paths distinguish the distances. RunRecs excludes these editorial routes as before.

Checks:

- `npm run verify:road-marathon-guides` for existing full-marathon regressions.
- `npm run verify:road-half-marathon-guides` for sources, URL uniqueness across distances, dates, results bounds, breadcrumbs and schema.
- `RUNNING_VERIFY_BASE=<origin> npm run verify:running-guides-ssr` for all 176 routes, internal links, metadata, distance labels, results links, sitemap inclusion and unknown-route 404s.

Mobile browser navigation from the UK half-marathon guide to Great North Run was checked with no page errors. Source checks do not claim that every race or every historical result is covered.
