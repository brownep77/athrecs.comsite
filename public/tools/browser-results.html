Can’t drag it? Add the bookmark manually
  1. Bookmark this page, then right-click the new bookmark and choose Edit.
  2. Set its name to Save results to AthRecs.
  3. Replace its URL with the complete code below, including javascript:, and save.

2. Try one results page

  1. Open London Marathon 2026 results in Chrome and display a list of runners.
  2. Click Save results to AthRecs in your bookmarks bar.
  3. Choose the table, check the sample and click Collect all pages for a supported London listing, or Send to AthRecs for just the loaded page. An AthRecs tab opens; click Continue to import.

Start on page 1. The London collector follows the source’s next-page links for the filters you selected. Remove a women-only, age-group or name filter first if you want a wider field. Keep both tabs open; pause or resume from the results tab.

Standard HTML tables, accessible tables and responsive lists with column labels are supported. London’s 2026 list layout is supported. Use a wide desktop window so all column headings are visible. If no panel appears, the site may block bookmark scripts. If no table is recognised, keep the page URL and tell us what happened.

3. Check, save and review athletes

AthRecs guides you through the source, exact race edition and a readable preview. Recognised headings are mapped for you. Confirm them, then click Save and collect all pages. AthRecs saves each page into the private claimable results pool before requesting the next. For single-page imports, use Save results for athlete matching.

Sign in to the staff backend before starting an automatic collection. The collector stops on a blocked request, changed headings, changing totals or repeated runners. It does not bypass access checks. If a tab is closed, restart from page 1; saved rows are checked for duplicates.

Use Add to a saved race for later pages so AthRecs keeps the same race source and checks repeated rows. The saved screen takes you directly to athlete review. Unmatched entries can appear as private suggestions when athletes sign in and request their results.

The receiving tab keeps pending captures in this browser for up to 24 hours so you can sign in first. Nothing is written to the results database until you confirm the import. All-pages collection requires one confirmation for the selected race and filters; it then saves each page automatically. Sending or saving does not establish identity, publish profiles or grant account ownership.

Have a downloaded file, or the new tab was blocked?

Choose Download a file instead, then open Import a race and drop the .athrecs.json file into the upload box. CSV and TSV are also supported.

Use sources you are authorised to retain. The button reads the selected visible table and its row links. It does not read cookies, passwords or browser history, and sends selected source data only to AthRecs. Automatic collection uses normal same-site page requests after staff confirmation, one page at a time, and stops on errors. Athlete identity and publication remain separate reviews.
